# 🌐 Web Development Utilities

Esta sección centraliza fragmentos de código, estructuras CSS y utilidades de JavaScript diseñadas para optimizar el desarrollo web front-end, siguiendo principios de limpieza y reusabilidad.

---

## 🛠️ Utilidades Disponibles

### 1. Carga Dinámica de Componentes (`js/ComponentLoader.js`)
Utilidad basada en la **Fetch API** de JavaScript para cargar archivos HTML externos dentro de un contenedor específico. 

- **Problema que resuelve**: La duplicación de código en el Header y Footer en sitios web estáticos (sin frameworks).
- **Técnica**: Promesas (Promises) y manipulación del DOM.
- **Beneficio**: Facilita el mantenimiento; cambias el Header en un solo archivo y se actualiza en toda la web.
